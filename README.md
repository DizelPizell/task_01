# Task: stock_2025_07_avg25.csv

Скрипт `avg25.py` анализирует дневные остатки за 01.07.2025–31.07.2025.

Для каждой пары `item_id + location_id`:
1. Из анализа исключаются дни с `qty = 0`.
2. Считается средний остаток по оставшимся дням.
3. Среднее округляется до 0.001.
4. Ищется первый день, когда `qty < 25%` от округленного среднего.
5. В результат записывается только первая такая дата.

Запуск из каталога, где рядом со скриптом находится папка `stock`:

```text
python avg25.py
```

Либо можно явно указать каталог с дневными остатками:

```text
python avg25.py --stock-dir path/to/stock
```
