# Test task: daily stock calculation

## Запуск

Из корня проекта:

```bash
python stock.py
```

Скрипт автоматически:
- находит последний исходный файл `stock_YYYY_MM_DD.csv` и использует его как начальный остаток;
- читает файлы `invent_trans/invent_trans_YYYY_MM.csv`;
- агрегирует движения по `item_id`, `location_id` и дате;
- рассчитывает остаток на конец каждого дня;
- создаёт `stock_YYYY_MM_DD.csv` в каталоге `stock/`.

По умолчанию расчёт идёт от дня после начального остатка до последней даты в файлах товародвижения.

## Формула

Для каждой пары `item_id + location_id`:

`остаток_конец_дня = остаток_начало_дня + сумма(qty)`

`себестоимость_конец_дня = себестоимость_начало_дня + сумма(cost_amount)`

Отрицательные значения движения учитываются как расход, положительные как приход.

Для денежных и количественных значений используется `Decimal`, чтобы избежать ошибок округления бинарного `float`.
