# Тестовое задание 02

Скрипт `top10.py` формирует два файла TOP-10 товаров по сумме себестоимости в каждом подразделении на 31.07.2025.

## Запуск

Запуск из каталога `task_01`:

```bash
python top10.py
```

По умолчанию входные данные берутся из `invent_trans/` и `stock/` рядом со скриптом, а результаты записываются в `stock/`.

## Логика

Сначала из `stock/` берётся исходный снимок с самой ранней датой (`stock_2025_04_30.csv`). Движения за май-июль агрегируются по дате, товару и подразделению. Остаток последовательно рассчитывается по дням до 31.07.2025.

### top10a

В выборку попадают позиции, у которых количество остатка было положительным на конец **каждого дня** периода 01.05.2025-31.07.2025. Дополнительно исключаются позиции с нулевым количеством или нулевой себестоимостью на 31.07.2025.

### top10b

В выборку попадают позиции, которые перешли из отсутствия остатка в положительный остаток в период 01.07.2025-10.07.2025 и после этого имели положительный остаток на конец каждого дня вплоть до 31.07.2025. Дополнительно исключаются позиции с нулевым количеством или нулевой себестоимостью на 31.07.2025.

Для каждого подразделения выбираются 10 позиций с максимальной себестоимостью на 31.07.2025. При одинаковой себестоимости используется `item_id` как детерминированный tie-breaker.

Для денежных и количественных значений используется `Decimal`, чтобы избежать ошибок округления `float`.
